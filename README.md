# 九九モンスタークエスト (Kuku Quest) ⚔️🐲

子どもが楽しく九九（1〜9の段）をマスターできる、ブラウザ完結型の学習RPG風Webゲームです。

ブラウザで開くだけで、スマホ・タブレット・PCのどこからでも遊べます！

---

## 🌟 ゲームの特徴

1. **テンキー＆キーボード両対応**
   * タブレットやスマホでは大きな数字ボタンをタップして直感的に入力。
   * パソコンのテンキー・キーボード数字入力・Enterキーにも完全対応。
2. **ランダム＆バランス出題**
   * 1〜9の段からまんべんなく抽出された全10問に挑戦。
3. **正確性 ＋ スピード評価システム**
   * **一発正解**：迷わず答えられると高得点（100pt）。
   * **スピードボーナス**：早く解き終わるほど大量ボーナス加算！
   * **ノーミスクリア賞**：10問連続一発正解で+300pt！
4. **歴代ハイスコア TOP 5 ランキング**
   * 過去の上位5位までの記録（スコア・タイム・日付）を自動保存。
   * ランクインするとピカピカ光ってお祝い！
5. **外部通信なし・完全ブラウザ完結**
   * HTML/CSS/JavaScriptの1ファイル構成。
   * 音声もブラウザのWeb Audio APIで生成しているため、外部通信や読み込み遅延が一切ありません。

---

## 🎮 遊び方
1. 「スタート！」ボタンを押すとゲームが始まります。
2. 画面に表示されるモンスターの九九問題（例：`7 × 8 ＝ ?`）に答えます。
3. 数字を入力して「こうげき！」（またはEnterキー）を押します。
4. 10問解き終わると、あなたのスコア・タイム・称号が表示されます！
